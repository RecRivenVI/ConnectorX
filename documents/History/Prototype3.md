# 原型 3：实体设备镜像

当前版本 `0.3.2-prototype3` / versionCode 7，仍为同一 ConnectorX APK，入口为 **设备镜像**。按用户最新决定，圆角使用系统参数 + 自有 G2 计算，挖孔遮罩暂时关闭；原型 1/2 入口保留。

当前曲线设计见 [G2 决策](../Decisions/0006-G2Corners.md)。0.3.1 的蒙版研究与历史交付见 [记录](Deliveries/Prototype3Delivery.md)，不代表当前版本仍按 PNG 绘制圆角。

0.3.2 已安装到两台设备，配对保持不变；构建、27 项测试及只读参数查询通过，视觉待用户确认。见 [G2 交付记录](Deliveries/G2PreviewDelivery.md)。

## 操作

1. 更新后重新打开两台 ConnectorX，被控端开启接收并启用 Shizuku。
2. 控制端点击已配对设备下的 **设备镜像**，无需重新配对。
3. 视频按被控设备比例居中，上下预留约 1.5 倍本机状态栏高度，外侧显示灰色边框。
4. 底部 **几何** 查看“G2 连续圆角预览”、系统半径、有效尺寸参数和挖孔关闭状态；**返回/桌面** 控制远端，**退出** 结束。
5. 可以与原来的普通镜像比较；旋转时应同步视频、裁切和输入，在几何快照同步期间暂停触摸。

## 当前 G2 预览

两台统一使用系统四角参数：popsicle 当前为 170px，shennong 为 147px。每个角采用两段三次 Bézier，与直线连接时曲率降为 0，中间接点曲率连续。切线过渡区约为参数的 1.5 倍；系统参数缺失/为 0 的角保留直角，极端尺寸才按比例缩小参数以避免重叠。

ConnectorX 自己叠加的挖孔、PNG 蒙版和 cutout 路径均不绘制；触摸也不再按孔洞排除。不会修改远端原始视频中已包含的像素。未来恢复挖孔时仍使用具体贴图，当前不猜测孔洞。

## 验收边界

本轮可以核验参数读取和蒙版来源，但新界面的实际视觉、多指、边缘触摸及旋转仍由用户测试。重点检查灰边是否无缝贴合且不压住直线区域，圆角/挖孔是否与被控设备一致。

窗口很窄、三键导航或控制区域空间不足时，布局会增加对称留白以避免覆盖镜像。当前只镜像主 Display 0，不将 popsicle 的背部副屏误作主屏。

P2 通知栏/导航栏是否悬浮覆盖仍待讨论；本轮不作最终设计决定。音频、宏、公网及最终 UI 管理继续后续开发。参数探针和图片均直接保存电脑端项目临时目录，不在 Android 内落盘。
