## 远程应用模式

快捷方式保存稳定设备 ID 与包名（用户/profile 标识扩展待研究），不保存 IP 或认证秘密。点击后先认证，再确保对应虚拟 Display 与目标 Activity。离线、权限失效、应用已卸载、拒绝副屏启动等情况必须显示可恢复原因，不静默转为主屏启动。

尺寸使用当前控制端窗口/屏幕的实测像素与密度信息，区分物理像素、dp、编码尺寸和远端 density。目标为满屏内容延伸到本机系统栏之后；远端 system decorations 单独关闭并实测。必要的编码对齐、带宽和比例限制应报告实际协商尺寸。

刷新率区分远端 Display 模式、应用帧率、编码输出帧率和控制端呈现帧率。记录请求与实际值；不能用 max-fps 参数证明 Display 刷新率匹配。

2026-09-07 最新决定：独立应用模式暂停远端 padding/Insets 代理，视频及真实虚拟 Display 均以本机系统栏以内的可用区域为准。控制端背景纯黑，栏图标为浅色，栏保持可见；读取本机 systemBars/cutout 的并集以避免重复扣除顶部尺寸，并兼顾横屏侧边挖孔。远端仍关闭 system decorations，不注入布局 Insets。后续背景特效及全屏跟随另行处理；管理页和完整镜像不受此变更影响。IME 出现时验证布局及坐标；系统栏区域由系统接收的手势不可当作普通远程触摸。

2026-09-07 用户反馈：原型 2 目前符合预期，但系统栏是否悬浮覆盖仍待讨论。当前实现保留供比较，不代表该视觉策略已通过最终设计确认。

## 导航候选语义

| 输入 | 首轮目标 / 待测边界 |
| --- | --- |
| 普通触摸、多指 | 经视频变换映射到目标 displayId，验证 pointer 生命周期 |
| 本机返回 | 控制画面内映射远端 Back；本地对话框优先关闭；远端任务根部退出语义待测 |
| Home / 最近任务 | 原型默认保留本机行为；另行验证显式远端导航入口 |
| 系统边缘手势 | 不承诺普通 APK 能全局拦截；测试系统可提供的事件与边界 |
| 键盘 / IME | 分别验证按键、文本、组合输入和多语言；不假设发送 keycode 等同完整输入法 |

Home 行为为候选策略，非已证明的系统拦截能力。用户必须可以正常返回本机环境。

## 旋转

0.3.6 栏背景更新：保持上述可用区域，顶/底栏用视频最外一行像素延展并应用 Miuix progressive blur（画面侧 1dp、外侧 10dp），替代纯黑。左右及首帧前仍黑色；视频本身和系统图标不参与模糊。

控制端自己读取传感器并提出旋转意图，不让本机传感器直接驱动独立应用 Activity。远端实际 Display 状态确认后，再驱动控制端整个 Activity；尊重应用方向限制。请求编号与显示状态版本分离，兼容应用自主旋转和无变化结果。同步 displayId、自然方向基准、方向、视频尺寸和输入映射代次，切换期间取消活动触点，避免旧坐标注入新布局。本机旋转后仍需回传更新的 Insets，但不得生成重复旋转意图。当前产品尚未实现此闭环。

## 完整设备镜像几何

定义控制窗口宽高 W、H，当前状态栏高度 S；源屏幕宽高 w、h；边框向外厚度 t。初始目标内容高度 `H - 3S`，内容宽度按源比例计算。为避免横屏/宽设备溢出，候选缩放为：

```text
scale = max(0, min((H - 3S - 2t) / h, (W - 2t) / w))
contentWidth = w × scale
contentHeight = h × scale
```

外框整体居中，目标上下各至少约 1.5S；额外宽度约束时可能留更多空间。此处按外框预留空间是初始解释，P3 通过截图评审确认。折叠姿态、横屏和本机 cutout 遮挡时记录限制，避免强行拉伸。

优先研究系统 DisplayCutout 路径/bounding rect、overlay 中裁切定义和圆角信息。元数据需携带来源显示、原始坐标尺寸、方向、密度与可用精度，裁切、视频、黑色孔洞和输入共用同一变换。

- 方案 B 优先：真实系统路径；分别证明 cutout 与 rounded corner 是否完整，不能假设一个 path 包含两者。
- 方案 A 候选：四角中心/半径近似，不能声称得到连续曲率。
- 不可读时显式 degraded，说明矩形/半径近似；不引入人工机型数据库伪造高精度。

屏幕有效区域裁切视频；灰色边框从内容外缘向外生成。直线内边缘紧贴内容、不覆盖、不留缝；圆角外/刘海等非显示区域允许遮挡。前摄孔按真实几何在视频上绘制纯黑填充，无额外描边。边框不是居中 Stroke；复杂路径偏移、抗锯齿接缝与边框厚度须在 P3 单独检查。

当前预览调整：用户改为系统半径 + 自有 G2 连续圆角，暂时关闭挖孔遮罩，只比较圆角效果。未来挖孔仍需贴图来源，不能由该 G2 算法推算。上述真实蒙版路线保留为历史研究，不再是当前圆角绘制方式。
