# ADR 0006：系统参数 + 自有 G2 圆角预览

日期：2026-09-07；版本 `0.3.2-prototype3` / versionCode 7。用户改变此前 PNG 圆角方案，要求先预览自有 G2 曲线并暂时禁用挖孔。

## 绘制与输入

读取自然方向的四个系统半径作为造型尺寸参数。由 `G2Corners` 生成两段三次 Bézier，直接使用 Android Path.cubicTo 绘制，不用折线采样模拟连续性。视频裁切、外框与触摸区域共用生成的轮廓及现有旋转变换。

灰边仍通过裁掉 2t stroke 的内半边，向视频外侧扩展 t。若相邻圆角的过渡长度超出边长，则统一缩小四个参数以避免重叠。半径为 0 时保留直角，不宣称该角具备 G2 连续性。

停止叠加 PNG 或 cutout 路径，并移除相应孔洞触摸排除；活动元数据查询不再加载 PNG。原始视频像素不改写。未来摄像头仍应使用具体贴图，本算法仅负责圆角。

## 曲线定义与连续性

令系统尺寸参数为 r，归一化量：

```text
s = 1.5
m = 1 - 1/sqrt(2)
c = (15m + sqrt(12ms - 15m²)) / 6
```

左边向上边过渡的规范角控制点（各坐标乘 r）：

```text
第一段：(0,s), (0,c), (0,2m), (m,m)
第二段：(m,m), (2m,0), (c,0), (s,0)
```

- 与直线相邻的三个控制点共线，且端点速度非零，因此端点曲率为 0，与直线匹配。
- 中间接点相同、切向量相同；两侧曲率均为 `(c-2m)/(3√2 m² r)`，满足 G2。
- c 的选择令中间曲率驻定；归一化曲率从 0 上升至约 `1.3165313346/r`，再对称下降，避免中间形成曲率凹陷。
- 中间点保留名义圆角半径 r 的对角线内缩量，沿直边的过渡跨度扩大到 1.5r。

这是 ConnectorX 的自定义连续曲率造型，不是从系统参数恢复出的真实面板曲率；视觉大小和平滑程度由用户此次验收。

## 验证

新增 6 项数学测试，检查端点零曲率、切线方向、中间接点切向量/曲率相等、曲率单调性、非退化速度、尺寸拟合及无效参数。设备最终视觉与边缘触摸仍由用户操作确认。
