# 画面与音频

你可以在“设置 → 画面与音频”调整新会话的清晰度、流畅度和声音。保存或恢复默认不会打断当前连接。本机应用直连显示不经过这些编码参数。

视频组提供分辨率上限、帧率上限和码率。视频码率使用 Mbps，100 Mbps 直接填写 `100`；音频高级项使用 kbps，128 kbps 填写 `128`。保存时再换算，不改变已有设置和范围。

声音组提供开关、声音来源和被控设备外放。“全部系统声音”可能包含其他应用；“应用播放的声音”才支持同时外放，仍受应用捕获策略限制。受保护媒体不在支持范围。

“高级”默认折叠，包含视频编码、音频编码和缓冲。编码格式须被控设备支持；更高码率不一定降低延迟，兼容选项保持默认通常更稳妥。全部字段、默认值和范围见[参数参考](../reference/configuration-media.md)。

需要查看会话数据时，在“设置 → 高级”开启“显示会话诊断”，再打开会话的“功能”。解码输出不等于屏幕实际刷新率，相对积压不是端到端延迟。
