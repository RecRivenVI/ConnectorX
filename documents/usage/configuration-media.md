# 画面与音频

你可以在“设置 → 远控画面与音频”调整新会话的清晰度、流畅度和声音。保存或恢复默认不会打断当前连接，需要新建会话后观察效果。本机应用直连显示不经过这些编码参数。

先使用默认配置。如果画面跟不上操作，先降低分辨率或帧率，再考虑码率和编码器。更高码率不一定降低延迟；编码格式必须由被控设备支持。码率单位是 bps，100 Mbps 对应输入 100000000。

音频可以单独关闭；部分应用禁止音频捕获，受保护媒体不在支持范围。系统音频可能包括其他应用声音，不能当作只采集当前独立应用。

质量面板可查看接收与解码输出帧率、媒体吞吐、积压和音频缓冲。解码输出不等于屏幕实际刷新率，相对积压也不是端到端延迟。

所有字段、默认值和范围见[参数参考](../reference/configuration-media.md)。
