# 打开远端应用与镜像

你可以从已配对设备打开指定应用，或查看完整设备画面。前提是两端在线且被控设备权限可用。

“应用”页可打开目录、常用/最近项目和继续已有会话；“设备”页可进入设备控制。远程应用也能添加桌面快捷方式，直接连接对应设备和包名。

独立应用默认避开本机状态栏和导航栏。你可以在该应用的菜单中保存两处下沉选择；同包名共用设置。远端系统栏开关影响下次新建会话，和本机栏下沉分别控制。“强制重开”只重启当前目标应用，未保存内容可能丢失。

从画面外或本机系统栏开始的触摸不操作远端；从有效画面内开始的滑动可以连续越界。返回发送给目标应用，本机 Home 保留本机行为。

进入后台会保留会话，恢复时重新显示；“退出”会结束对应控制并释放其显示。停止接收只停止新连接，不替代退出。系统杀进程、安装更新或网络故障仍可能中断会话。

画面圆角是近似造型；没有可信挖孔位置时不绘制孔洞。性能参数见[画面与音频](configuration-media.md)。
