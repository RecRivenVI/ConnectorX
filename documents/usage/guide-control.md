# 打开远端应用与镜像

你可以打开已配对设备上的指定应用，或查看完整设备画面。两端应在同一局域网，且被控设备控制权限已就绪。

在“应用”页选择设备，目录会自动读取；下拉可以刷新，失败时选择“重试”。点应用打开，右侧更多提供常用、已有的桌面快捷方式、显示设置和应用信息。“继续使用”可以回到保持中的会话。

“设备”页点卡片进入详情，可打开应用、镜像或回到已有会话。未在附近发现不代表配对失效，可以重试并检查双方连接状态。

会话顶部的“ConnectorX”回到主界面并保留会话，“功能”提供该类型已有的文本、显示、重开和诊断能力。底部依次为最近任务、桌面和返回，右侧上/停/下支持点击及按住滑动。副屏桌面与最近任务的行为取决于系统。

远程应用使用居中的比例预览。按应用保存的状态栏/导航栏延伸选项决定下次打开时请求的可用尺寸；预览缩放不降低虚拟屏请求分辨率。显示远端系统栏影响下次新建会话。“强制重开应用”只重启当前目标，未保存内容可能丢失。

从画面外或本机系统栏开始的触摸不操作远端；从有效画面内开始的滑动可以连续越界。返回发送给目标应用，本机系统 Home 保留本机行为。

进入后台会保留会话；“退出”确认后结束对应控制并释放其显示。停止接收只停止新连接。系统杀进程、覆盖安装或网络故障仍可能中断会话。

没有可信挖孔位置时不绘制孔洞。诊断需在“设置 → 高级”开启，参数说明见[画面与音频](configuration-media.md)。新远端预览布局、持续滚动和坐标仍需双机人工验收。
