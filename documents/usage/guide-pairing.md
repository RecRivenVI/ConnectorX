# 配对并连接设备

你可以把两台 Android 设备配对一次，之后在同一局域网再次连接，无须每次重做产品配对。

1. 在被控设备打开应用，让 Shizuku 保持运行并完成首次授权。
2. 在“设备”页确认接收已开启；应用启动会尝试开启接收并连接已运行的 Shizuku。
3. 控制设备选择附近设备；发现不可用时使用手动地址。
4. 双方核对相同校验信息并确认配对。
5. 选择远程应用或设备镜像开始操作。

离线、地址变化和权限失效不会删除配对。设备重启后可能需要重新启动 Shizuku；产品关系仍然保留。重装应用或丢失密钥会产生新身份，不能只凭设备名称信任它。

只接受你认识并能核对的设备。撤销配对后再次连接需要重新确认。后续操作见[控制说明](guide-control.md)。
