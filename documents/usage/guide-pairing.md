# 配对并连接设备

你可以把两台 Android 设备配对一次，之后在同一局域网再次连接，无须每次重做产品配对。

1. 在被控设备打开 ConnectorX，进入“设备 → 添加设备 → 让这台设备被控制”。
2. 确认“允许其他设备连接”已开启，然后开启“接受新的配对请求”。入口开放两分钟，到时自动关闭。让 Shizuku 保持运行并完成首次授权。
3. 控制设备进入“设备 → 添加设备 → 控制另一台设备”，选择附近设备。找不到时展开“输入地址”，填写对方显示的局域网地址。
4. 双方核对校验码，数字一致才选择“一致，配对”。确认后，对方可以查看并控制本机屏幕。
5. 配对完成后选择“打开应用”，或回到设备页打开镜像。

应用启动会尝试开启接收并连接已运行的权限服务；首次授权和启动服务仍需要你操作。两分钟入口目前不能提前关闭，已配对设备不受这个入口影响。

离线、地址变化和权限失效不会删除配对；设备详情提供重试。设备不在附近且没有现有连接时，“打开应用”和“设备镜像”不可用；重新发现或连接后再使用。重装应用或丢失密钥会产生新身份，不能只凭设备名称信任它。

只接受你认识并能核对的设备。解除配对需要确认，会立即撤销对方权限并中止连接；再次连接需要重新确认。后续操作见[控制说明](guide-control.md)。
