# 全局悬浮控制

你可以在本机其他应用上持续上滚或下滚，无须打开镜像。在“自动化”选择“全局悬浮控制”，首次按系统提示授予悬浮窗权限，并确保 Shizuku 已运行和授权。

点击上滚或下滚开始，再次点击同一方向停止；中间停止按钮随时停止。也可按住在三个按钮间滑动选择，松手保持方向。

顶部圆形按钮用于拖动，松手吸附到左右各三个固定位置之一，首次在右上。拖动会先停止滚动。底部退出只关闭悬浮控制，不关闭其他会话；通知和自动化页面也提供停止入口。

锁屏立即停止，窗口和点位保留，解锁不会自动继续。安全锁屏可能遮住悬浮窗；系统结束服务后不会自行恢复滚动。悬浮窗不会自动淡出。

这是原生滚轮操作，应用可以自行决定是否响应，并非手指滑动或完整触摸宏。
