# 本机应用

你可以把本机指定应用放入独立虚拟屏的小窗中操作，无须经过网络传输；该模式不镜像本机主屏。

在“应用”页选择本机应用并打开。顶部“功能”提供当前应用设置（诊断需在设置的高级分组开启），“退出”结束该会话；底部依次是最近任务、桌面、返回。副屏桌面与最近任务行为取决于系统支持。

右侧上/停/下控件支持点击与按住滑动。松手保持选择，再次点击当前滚动方向可停止；选择另一方向直接换向。实际速度由目标应用的滚轮响应决定。

键盘显示在虚拟屏内，预览比例不随键盘缩小。键盘正在显示时，第一次返回先收键盘，后续返回才作用于应用。其他输入法或系统版本仍可能有兼容差异。

重启、退出、画面分离或异常会停止持续滚动，不承诺息屏继续执行。独立全局控制见[全局悬浮控制](feature-global_scroll.md)。
