## 开放项

- 配对入口保持两分钟自动关闭；提前关闭没有现成 API，本轮不扩展其安全控制。
- ADB 键盘返回测试曾使宿主离开前台，后续坐标点击误开相机；未拍摄/录制，已恢复到 ConnectorX、无活动相机客户端。无法据合成按键判定实际返回手势表现，需人工复测。
- 未覆盖无权限、读取失败、配对成功/拒绝等需要改变当前用户权限/身份或第二台设备的真机状态；界面映射单测不能替代这些流程。
- 当前没有 Android Studio，未执行其默认格式化器；新页面未补齐 IDE 预览（C-01、AN-10）。文本已统一 UTF-8/LF，资源两套同步。
- Android-only UI 仍用 KMP 源集；后续迁移应保持资源包、入口与本地化。Shizuku/Root 跨 ROM 不等价。
- 原创部分整体分发许可证仍待用户决定；已有第三方许可和署名保留。
