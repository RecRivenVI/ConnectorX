# 后续工作

优先稳定已实现的 Android 控制路径，范围由[产品定位](overview-product.md)限定。

| 顺序 | 工作 | 完成依据 |
| --- | --- | --- |
| 1 | 全局六点有限磁吸手感验收 | 用户完成慢拖、快拖、反向拖离和松手停靠场景；不以组件测试代替 |
| 2 | 双机身份、重连、权限失效、Surface 恢复和撤销 | 按跨设备场景验证，包括负向认证和既有存储 |
| 3 | 本机 LOCAL IME、系统装饰锁屏恢复及两步返回 | 真机键盘、目标应用、ROM 矩阵；不恢复虚拟 Insets/强制焦点 |
| 4 | 真实旋转闭环与远端应用尺寸语义 | 远端实际 Display 状态驱动本机，输入/视频同步，方向锁定与游戏实测 |
| 5 | 传输和呈现性能基线 | 区分网络接收、codec 输出、实际上屏和输入到显示；以测量决定优化 |
| 6 | 渐进偿还存量代码与界面债务 | 见[技术债](debt-existing_code.md)，每次锁定行为与验证范围 |
| deferred | 宏录制/编辑、条件、精确设备端回放 | 后续用户明确启动，复用输入引擎 |
| deferred | 公网/NAT/relay、文件和完整剪贴板 | 后续独立产品范围与安全设计 |
| deferred | 可选安全窗口捕获 | 仅评估 FLAG_SECURE，不碰 DRM/受保护媒体；不得把权限身份当完成证据 |

Windows 和 Flutter 不在计划中，不保留半成品入口。许可证选择需要用户决定，第三方义务不因此暂停。
