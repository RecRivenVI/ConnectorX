# 界面偏差修复与 Release 安装

## 目标

修复媒体参数、设备操作、状态标签、说明脚注及设备图标五处界面偏差，核对应用标识，以 Debug 签名的 Release 包安装到 shennong。安装后由用户验收，不启动、不操作应用。

## 范围

只调整界面与相应文档，保持媒体参数的存储格式、取值范围和会话行为。scrcpy 子模块不动。设备仅允许安装与读取包信息，保留旧包及数据。

## 步骤

1. 完成：核对媒体选项、设备状态、现有图标和应用标识，修复五处偏差。
2. 完成：同步使用说明、来源记录、更新日志与进度；Android Studio 格式化、本地完整构建、单元测试及 lint 完成。现有用例/结果和 lint 条目与基线一致，新增用例覆盖实际交互缺陷。
3. 完成：五处修复作为一次 Update 源码检查点推送 origin/main；标识已一致，不另建包名提交。
4. 完成：确定检查点之后的交付边界：仅通过本机参数为 Release 包指定 Debug 签名，加锁安装并读取包信息核对，释放锁后停止。实际安装结果保留在仓库外，不在计划中累积安装流水。

## 结果

源码修复与标识核对完成。未改变媒体存储、范围或 scrcpy 子模块；无需迁移旧包数据。本轮按用户要求不执行 U-08 / AN-15 的运行截图检查，也不验证显示变体，界面效果由用户验收。安装为源码检查点之后的交付操作，不能当作运行成功证据。
