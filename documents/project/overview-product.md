# 产品范围

ConnectorX 让配对后的 Android 设备成为本机的扩展应用运行环境。核心路径是一次双方确认配对，以后直接打开远端指定应用或完整设备镜像，并自然地触摸操作。

## 当前能力

- 局域网发现、手动地址、持久身份、双向认证与再次连接；权限激活独立于产品配对。
- 远端主屏控制、实体外观镜像、真实 VirtualDisplay 中的指定应用，以及桌面快捷方式。
- 本机指定应用的 VirtualDisplay 直连预览；本机不提供主屏镜像。
- 本机持续滚轮与独立全局悬浮控制；这些不等于宏录制或编辑器。
- 逐包名显示偏好、媒体配置和质量指标；主题与四栏导航。

实现存在不等于所有 ROM 已验收，当前覆盖与开放项见[进度](status-current.md)。

## 后续范围

触摸宏将复用特权输入引擎，在设备端按单调时钟调度。录制、多指时间轴、条件控制、完整宏管理、公网连接、NAT/relay、文件与完整剪贴板同步尚未完成，不创建空工程或假入口。

Windows 与 Flutter 开发已停止。产品仅面向 Android 间互联。Go 只在确有独立网络基础设施需求时评估，不重写 Android 显示和输入实现。

可选 FLAG_SECURE 处理仍是[提议](../design/adr-8-secure_window_capture.md)，不把 Root 身份等同于能力完成；不处理 DRM、受保护缓冲区或安全媒体链路。
