# 产品目标与范围

ConnectorX 将 scrcpy 已有 Android 控制能力产品化为跨设备运行环境。远程控制与后续触摸宏属于同一应用，共享权限、设备、显示、输入与捕获能力。当前实现以 [开发基线](CurrentState.md) 为准；原始长提案保存在 [历史产品目标](History/OriginalProduct.md)。

## 正式开发优先级

1. 巩固持久配对、认证和权限生命周期：配对身份与地址/ADB/权限失效分离。
2. 完成远程指定应用体验：真实 VD、自然输入、包名设置、可靠恢复与错误反馈。
3. 完善完整设备镜像：当前 G2 造型与真实几何来源明确区分，挖孔以后使用真实贴图。
4. 在稳定底层上推进宏、完整 UI/UX、公网。

## 当前产品约束

- Compose + Miuix；优先复用官方 scrcpy，不用 Go 重写 Android 系统接口。
- 控制端默认保留系统栏可用区域；允许逐包名下沉到通知栏/导航栏。系统栏起手不转发普通触摸。
- 远端系统装饰逐包名选择，默认关闭；实际栏由远端 ROM 决定。不注入远端 Insets，不添加边缘模糊。
- 返回为普通返回键；预测性返回已撤回。
- 连接不随页面或 Surface 生命周期主动终止；显式断开、撤销与真实传输失败另行处理。
- 传感器意图→远端实际旋转→本机 Activity 的闭环仍是研究目标，不将视频拉伸当作完成。
- 宏在特权 runtime 按单调时钟回放；音频、完整剪贴板/文件、公网和 Windows 暂 deferred。

不预先承诺任意 ROM、Root/Shizuku 权限等价、受保护画面捕获或所有应用兼容。Windows x64 → Android 现纳入开发；Android 可向 Windows 主动镜像/投送应用，Windows 仍为控制方，明确不提供 Windows 被控能力。
