# ADR 0005：设备镜像的真实几何与降级边界

## 状态

已被 adr-11 取代

## 背景

本记录保留当时的产品决策原文，当前规格见[架构](architecture-android.md)及[交互](principle-interaction.md)。

## 决策

日期：2026-09-07。复用原控制、配对、编解码；P1 普通镜像、P2 远程应用保持入口，新增 P3 设备镜像。

### 选择

1. 在已有 Shizuku 框架线程只读查询主 Display 0，取得自然尺寸、方向、系统四角半径、DisplayCutout 路径。按资源名称从 SystemUI 当前 overlay 解析蒙版，禁止机型判断表或把已提取 PNG 内置为设备模板。
2. 有完整上下蒙版时，以 alpha 中外缘连通部分构建像素精度轮廓，用 PNG alpha 在内部绘制纯黑孔洞，不额外描边。缺少蒙版时只按系统 radius 近似；矩形预留区不作为真实孔洞。
3. 0.9.0 起新入口改用 SurfaceView 直接承载 MediaCodec 输出。G2 轮廓、灰色边框和未来挖孔由 SurfaceView 上方的不透明遮罩绘制，避免 TextureView 纹理合成；触摸仍依据同一几何路径判断有效显示区域。
4. 灰框以同一轮廓绘制 2t stroke，再裁掉轮廓内部，只保留向外厚度 t。它的内缘与视频裁切边界完全相同；不会通过居中描边侵占画面。
5. 主屏按真实比例居中，上下目标约 1.5 倍本机状态栏高度。系统栏/控制按钮空间不足时增加对称留白；横屏或宽设备额外受宽度约束，不拉伸。
6. 路径、蒙版和触摸共用自然坐标到当前方向的变换。孔洞和非显示角落不接收触摸，拖入时释放触点。视频 session 改变后暂停几何触摸，按新快照恢复；旧查询不得覆盖新视频代次。
7. P2 系统栏是否覆盖画面仍待用户设计决定，本轮不擅自修改。P3 自身系统栏正常可见。

### 不承诺的内容

蒙版 alpha 轮廓是像素级来源，不是原始连续曲率参数。缺失或分辨率不匹配的资源会降级；读取到保留矩形不能证明摄像头真实形状。Root 只用于本轮必要的只读资料获取，应用运行仍沿用 Shizuku。

实际参数来源见 [设备研究](../research/investigation-screen_geometry.md)，视觉/触摸验收由用户操作；头部/底部资源解析和只读探针结果不等于新渲染界面已验收。

## 后果

仅在上列状态和当前规格适用范围内继续执行，不把历史实验、提议或构建证据扩展为当前端到端能力。
