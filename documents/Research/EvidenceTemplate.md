# 实验记录模板

复制此模板到同目录下有明确主题的 Markdown 记录；大型输出放工作区 Artifacts，临时探针放 Scratches。引用脱敏证据路径，不提交私钥、配对秘密、设备个人内容。

- 实验 ID / 日期：
- 对应需求 / 原型验收项：
- 状态：pending / PASS / degraded / FAIL / deferred
- ConnectorX 版本与 scrcpy 固定提交：
- 设备 A / B 型号、Android API、ROM、显示形状：
- 权限方式、实际 UID/GID、SELinux 域：
- 先决条件（ADB、Shizuku、Root、网络、启动状态）：
- 源码路径 / 符号 / 官方链接：
- 假设与预期：
- 可重复步骤：
- 实际结果与测量方法：
- 日志 / 截图 / 视频 / 元数据证据路径：
- 失败、降级与覆盖范围：
- 清理步骤及设备恢复状态：
- 结论（区分源码事实、实测事实和推断）：
- 下一步与需要更新的架构决策：
