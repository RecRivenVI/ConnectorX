# 更新日志

采用 Keep a Changelog 分类；应用版本以应用构建配置为准。尚未发布的工作区改动在此归纳，不把历史安装流水冒充正式发行。

## [1.0.25] - 2026-10-22

### 修复

- 分辨率与帧率以“自动”“不限”、预设或“自定义”表达；仅自定义时展示数值输入，不暴露内部特殊取值，存储与范围不变。
- 离线设备详情禁用“打开应用”和“设备镜像”，保留重试入口。
- 设备状态改用统一的中性标签；自动化与媒体说明使用小号次要文字。
- 导航与设备卡统一使用 AOSP 手机图标，避免电话听筒含义。

## [1.0.24] - 2026-10-21

### 变更

- Miuix 对齐正式版；应用目录、设备详情/添加、自动化、设置和媒体页按任务重排。
- 应用选项与远端会话功能使用底部弹层；远端预览共用导航和滚轮控件，退出增加明确确认。
- 视频/音频码率界面改用 Mbps/kbps，高级项默认折叠，存储、默认值和校验保持。
- 会话诊断默认关闭，开启后集中在功能面板；主界面使用用户状态与下一步动作。

### 修复

- 权限服务稍后就绪时自动读取目录，同一本机身份不重复显示为设备 Tab。
- 固定顶栏子页不再消耗列表滚动，媒体高级项可正常访问。

远端新布局与双机流程、显示变体及悬浮手感尚待人工验收，见当前进度。
