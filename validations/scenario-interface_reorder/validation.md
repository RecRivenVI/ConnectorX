# 界面重排

## 目标

验证四栏导航、设备与应用状态、媒体单位和会话控制入口，同时保留配对身份、用户设置及已确认的本机/悬浮交互。构建不代替双机、显示变体和手感验收。

## 运行

1. 构建并运行标准 Gradle 单测和 lint；将现有用例与基线按类名、用例名、结果比较，另核对界面映射用例。
2. 安装同一候选，保留签名与数据；记录设置和设备文件列表。在授权设备上查看四页、设备详情/添加、应用选项及媒体高级项。
3. 验证本机应用打开、停止滚动、回到主界面、继续会话及显式退出；悬浮控制开/停/关后不遗留服务窗口。诊断默认关闭，开启时才出现指标。
4. 在双机环境验证已配对连接、离线重试、远端应用/镜像、导航、文本、滚轮、触摸越界与退出确认。只用独立测试身份验证新配对，不为覆盖测试撤销用户原配对。
5. 用人工手势验证键盘返回及手感；在另行允许的环境检查深浅色、最大字号、横屏和宽屏。不能验证的明确记为待验收，不改用户系统设置凑覆盖。
6. 结束本轮会话与悬浮窗，恢复设置，核对文件；截图与 XML 直接流到电脑，数据与结果不入库。
7. 在“画面与音频”切换分辨率“自动/不限/自定义”与帧率“不限/自定义”，确认只有自定义出现输入框，输入恰好等于预设值时仍能继续编辑。检查设备离线时详情操作禁用、状态标签无独立点击含义、设备图标一致、说明脚注为次要文字。仅在获得设备操作授权后执行；只安装任务不执行本项。

## 通过标准

- 现有测试用例及结果一致，新增码率、声音来源、设备/权限状态映射通过，lint 无新增错误或告警。
- 每种可到达状态有原因和下一步；名称/包名/地址/诊断按界面层级呈现，未实现功能没有入口。
- 回主界面/后台不结束会话；确认退出只结束目标，显示与输入的语义保持，原用户控制外观与操作不变。
- 设备上没有新增测试文件，配对/设置值保留。无法覆盖的环境及副作用差异已明确记录，不能写成完整通过。
