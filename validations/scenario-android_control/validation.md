# Android 双机控制

## 目标

验证持久身份、真实虚拟显示、实体镜像与会话生命周期，不以构建或安装替代用户操作。

## 运行

1. 取得当前安装及设备操作授权，记录两端应用提交、ROM、实际权限和网络。
2. 双方确认配对，断开后重新认证；再测试地址变化、离线、权限失效、撤销与未知身份拒绝。
3. 分别打开镜像和指定应用，验证系统栏/逐包名选项、快捷方式、强制重开与错误。
4. 检查外部起手拒绝、内部起手越界持续、多指独立准入和 CANCEL。
5. 后台/前台、Surface 重挂和停止接收期间保留既有会话；显式退出释放对应资源。
6. 原始结果写工作区 Artifacts/ConnectorX；截图经 exec-out 直接到 PC，不在设备存图。

## 通过标准

双方身份与授权匹配，未认证媒体/控制被拒绝；重连不重新人工配对。目标应用确在目标 Display，布局与触点规则符合当前设计。后台不主动断连，显式退出可回收；实际网络失效不伪报仍在线。安全负向、视觉与 ROM 未覆盖项分别记 pending/degraded，不能批量写 PASS。
