# 全局悬浮控制

## 目标

验证三段滚轮、六点停靠、有限牵引、锁屏和租约停止；真实手感由用户判断。

## 运行

1. 用户授权后开启悬浮控制；检查与应用内同样的图标、主题、点击及滑动选择。
2. 选择方向、再次点击停止、直接换向；系统 CANCEL 不误触发点击。
3. 从每个点慢拖、快拖、反向拖离，再松手；检查最近点及原点/同侧并列裁决，旋转和重新抓取取消旧动画。
4. 锁屏后解锁，确认停止且窗口保留；退出仅关闭悬浮控制，原会话继续。
5. 有界模拟租约中断/所有者死亡，确认不续滚；测试结束清理自己的控制器。
6. 原始轨迹、视频和手感反馈写工作区，不入仓库。

## 通过标准

窗口持续跟手，附近有限牵引而不吸死，快速经过不强吸，落点与规则一致。滚轮由 runtime 调度，无失控续滚；锁屏/拖动/退出及时停止。组件和数学测试只能支持状态正确，用户未验收手感时保持 pending。
