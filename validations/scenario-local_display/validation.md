# 本机应用与输入法

## 目标

验证完整分辨率直连预览、定向输入、LOCAL IME、两步返回与系统装饰锁屏恢复。

## 运行

1. 获得当前设备操作授权，以 shennong 为默认测试机，记录目标包、ROM 和输入法。
2. 打开本机应用，验证等比居中、完整虚拟分辨率、画面内外起手和多指。
3. 进入编辑框，确认键盘在虚拟屏；输入中文与预编辑，第一次返回隐藏键盘、第二次作用于应用。
4. 切换输入框、回到目录本地输入，再继续同会话，验证宿主 flags 恢复。
5. 开启系统装饰后锁屏/解锁，重挂 Surface，检查导航栏、Insets 与任务没有被重建。
6. 检查滚轮点击/滑动/同方向停止、分离与重启清零，结果和媒体只存工作区。

## 通过标准

目标收到 Display 定向事件，键盘不会因物理宿主触摸提前消失，隐藏失败不误注入 Back。预览/分辨率不因 IME 改变，系统装饰恢复不靠 padding 或 Insets 伪造。缺少设备/输入法样本时记无法比较或 pending，不扩展 shennong 结论。
